# devbank-xss-payload

Standalone JavaScript payload hosted for a university web-security assignment
(FIT5003 A2, Part B.2 — reflected XSS, account-takeover demonstration against a
local-only DevBank instance running on 127.0.0.1).

Loaded in the demo via jsDelivr:
`https://cdn.jsdelivr.net/gh/<you>/devbank-xss-payload@main/payload.js`

This repo contains ONLY the attack payload. No assignment source, fixes, or report.
